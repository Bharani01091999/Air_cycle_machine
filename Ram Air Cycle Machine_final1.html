Ram air cycle machine

Ram air → turbine → heat exchanger → duct → compressor → ambient. The turbine drives the compressor; this finds the airflow where their work matches, then checks the air can actually leave.

System layout

Numbers 0–6 mark the stations used in the table and equations. Each shows total temperature Tt and total pressure Pt. Values update when you press Calculate.

Cycle inputs

MFP = ṁ·√Tt / Pt with ṁ in kg/s, Tt in K and Pt in Pa. This SI form gives values around 1e-5 to 4e-5. For other units, set the factor so that data MFP = factor × this value.

Optional: flow areas and loss coefficients

The values filled in are placeholders; ram-air direct cooling needs the exit duct area. Clear an area and its K to go back to the fixed kPa drop above. An area alone adds Mach number and choke margin for that section. An area together with K makes that section’s pressure drop follow the flow: ΔPt = K · q, where q is the dynamic pressure at the section inlet (equation 13). The fixed kPa value is then ignored for that section.

Used when “Heat exchanger pressure drop model” is set to the velocity curve. It needs the heat exchanger flow area. The curve is scaled by the local air density divided by the reference density, and extended past its ends with ΔP ∝ V².

Optional: measured point

Enter any values you measured at the flight condition above. The dashboard compares them with the model result under “Model vs measured”.

Empirical data
Load maps from a file

CSV or text with three columns: MFP, pressure ratio, temperature ratio. A header row naming the columns is optional. Each file fills the π and τ boxes of its machine and recalculates.

Two columns per curve, one row per line. The π curves are MFP against π with π on the horizontal axis, as in your maps; the solver uses π as the unknown, so flat (choked) sections are fine. The temperature-ratio curves are τ against MFP, also with the ratio on the horizontal axis. Efficiency is calculated from π and τ and plotted with the π curve. Pick the other column order if your file has it reversed. Linear interpolation, ends held flat. Placeholder data: replace it with yours.

Equations used, in calculation order
1. Ram inlet (stations 0→1)

Tt0 = Ta(1 + 0.2M²)   Pt0 = Pa(1 + 0.2M²)3.5
Tt1 = Tt0   Pt1 = ηrPt0, where ηr is the recovery you enter, reduced by × [1 − 0.075(M − 1)1.35] above Mach 1 if that option is on

Slowing the air to rest raises its temperature and pressure (the 0.2 and 3.5 come from γ = 1.4). No heat is added, so Tt stays constant; the inlet only loses some pressure. The supersonic reduction is the MIL-E-5007D relation as quoted in B. Refs: A, B, C.
2. Corrected flow (MFP)

MFP = ṁ√Tt / Pt (× unit factor)
Turbine: ṁ = MFPt(πt) · Pt1 / √Tt1

One number that combines flow, temperature and pressure, so a machine map holds for any inlet condition. The turbine curve gives MFP for a chosen πt, and that fixes the airflow ṁ. Refs: A, D.
3. Isentropic efficiency

ηt = (Tt1 − Tt2) / (Tt1 − Tt2s), Tt2s = Tt1πt−(γ−1)/γ
ηc = (Tt5s − Tt4) / (Tt5 − Tt4), Tt5s = Tt4πc(γ−1)/γ

Compares real temperature change with the ideal, loss-free one for the same pressure ratio. Your temperature-ratio curves give τ at the MFP of each machine, and the dashboard calculates η = (1 − τt) / (1 − πt−(γ−1)/γ) for the turbine and η = (πc(γ−1)/γ − 1) / (τc − 1) for the compressor. Refs: A, B, E.
4. Turbine (1→2): temperature and pressure

τt = Tt2/Tt1 = 1 − ηt[1 − πt−(γ−1)/γ]
Tt2 = τtTt1   Pt2 = Pt1/πt

The turbine expands the air, so pressure and temperature both fall. Rearranging equation 3 gives the temperature ratio. Refs: A, B.
5. Turbine work

wt = cp(Tt1 − Tt2) = cpTt1ηt[1 − πt−(γ−1)/γ]   (kJ/kg)
Wt = ṁ wt   (kW, with cp in kJ/kg·K)

Energy the air gives up as it cools. Only the fraction ηm reaches the shaft (bearing and windage losses). Refs: A, E.
6. Heat exchanger (2→3)

Tt3 = Tt2 + ΔT   Pt3 = Pt2 − ΔPhx
Q = ṁ cp ΔT

ΔT is either fixed, or ε(Tsrc − Tt2) with ε the effectiveness and Tsrc the heat source temperature, so the air only cools the load if it is colder than the source. Q is the heat absorbed, the cooling the machine provides. Refs: B, E.
7. Duct (3→4)

Tt4 = Tt3   Pt4 = Pt3 − ΔPduct

Adiabatic duct: only friction loss in pressure. Ref: A.
8. Compressor (4→5): temperature and pressure

τc = Tt5/Tt4 = 1 + (πc(γ−1)/γ − 1) / ηc
Tt5 = τcTt4   Pt5 = πcPt4

Compression heats the air; a less efficient compressor heats it more for the same pressure ratio. Refs: A, B.
9. Compressor work

wc = cp(Tt5 − Tt4) = cpTt4(πc(γ−1)/γ − 1) / ηc   (kJ/kg)
Wc = ṁ wc   (kW)

Work the shaft must supply. It grows with the inlet temperature Tt4, which is why heating the air before the compressor makes the compressor harder to drive. Refs: A, E.
10. Exit duct (5→6) and exhaust

Tt6 = Tt5   Pt6 = Pt5 − ΔPexit
Air can leave if Pt6 > Pa.   Mexit = √(5[(Pt6/Pa)1/3.5 − 1])

The air leaves at ambient static pressure, so the compressor outlet total pressure must exceed ambient. The surplus becomes exit velocity; above Pt6/Pa = 1.893 the exit is choked. Refs: C.
11. Ram inlet capture area

A = ṁ / (ρaV), ρa = Pa/(287 Ta), V = M√(1.4 · 287 · Ta)

Freestream air tube the inlet must swallow to supply ṁ. Ref: B.
12. Matching: how the operating point is found

Work: ηmWt = Wc + Wload
Flow: MFPc(πc) from the compressor curve = ṁ√Tt4 / Pt4

The same air flows through every component (no bleed or fuel). For each trial πt, the work equation gives πc. The flow equation then holds only at the right πt, which the dashboard finds by search. Refs: A, D.
13. Flow-dependent pressure drop and choke check (optional areas)

F = ṁ√Tt / (A Pt) = √(γ/R) · M / (1 + 0.2M²)3   (SI units)
q = Pt[1 − (1 + 0.2M²)−3.5]   ΔPt = K · q
Choked when F reaches 0.0404 (M = 1, γ = 1.4)

F is the flow per unit area, found from the section inlet state. Solving F for M gives the section Mach number. The drop is a loss coefficient K times the dynamic pressure q, so it grows roughly with ṁ²Tt/(PtA²). Choke margin = (1 − F/0.0404) × 100. Exit nozzle area needed: A = ṁ√Tt6 / (Pt6 F(Mexit)). Refs: A, C.
14. Ram air direct cooling (ACM off)

ΔT = ε(Tsrc − Tt1), Q = ṁ cp ΔT
ṁ = Aexit Pt,exit F(Mexit) / √Tt, with Pt,exit = Pt1 − ΔPhx − ΔPduct − ΔPexit

With the turbine and compressor bypassed, the ram pressure alone pushes air through the exchanger, so the flow is set by the pressure available and the flow resistance (equation 13). This works when the ram air is colder than the heat source and Q meets the required load. The ACM is only needed when ram air is too warm to cool the load directly. Automatic mode picks ram air alone whenever it meets the load. Ref: B.
15. Flight envelope

T = 303.15 − 6.5h (h in km, up to 16 km), then 199.15 + 2.3(h − 16) up to 46 km
P = Pb(T/Tb)−g/(RL) in a layer with temperature gradient L, and P = Pbexp[−gΔh/(RT)] where T is constant

Indian Standard Tropical Atmosphere (ISTA7, Ananthasayanam and Narasimha, 1983): 30 °C at sea level, −6.5 K/km to 16 km (−74 °C), then +2.3 K/km to 46 km (−5 °C), constant to 50 km. Sea-level pressure is taken as 101.325 kPa. Pressure follows from the hydrostatic equation in each layer, and the temperature offset is optional. Each envelope cell repeats equations 1–14 at that Mach and altitude. If “Scale with total pressure” is on, the fixed kPa drops are multiplied by Pt0/Pt0,point, because at the same corrected flow a drop is proportional to the local total pressure. Sections with area and K already follow the flow. Ref: F.
16. Heat exchanger pressure drop from a velocity curve

V = M√(γ R Ts), ρ = Ps / (R Ts)
ΔPhx = ΔPcurve(V) · ρ / ρref

M follows from the flow per unit area (equation 13) at the exchanger inlet, and Ts and Ps are the static temperature and pressure there. Pressure drop in a core scales with ρV², so a curve measured at the reference density is scaled by ρ/ρref. Beyond the ends of your curve the drop is extended as V². Refs: A, B.
